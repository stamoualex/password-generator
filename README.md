# Password-Generator
A simple Python command-line tool that generates secure, randomized passwords. Users can customize the password length and choose whether to include numbers and symbols, with built-in input validation to handle invalid entries.
## How to run
1. Make sure Python is installed (python.org)
2. Download `Password Generator.py` from this repo
3. Open a terminal in the folder where the file is saved
4. Run this command:
python "Password Generator.py"
5. Answer the prompts:
   - Enter a number for the password length
   - Enter y or n for numbers
   - Enter y or n for symbols
6. Your password will be printed in the terminal
